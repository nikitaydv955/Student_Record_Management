# Student Management System (SQL)

## Project Overview
This project is a simple Student Management System built using SQL. It demonstrates basic database operations such as creating tables, inserting records, updating data, deleting records, and retrieving information using SQL queries.

## Features
- Create Student Table
- Insert Student Records
- Retrieve Student Information
- Update Student Data
- Delete Student Records
- Use Aggregate Functions (COUNT, MAX, MIN, AVG)
- Apply Filtering using WHERE Clause
- Sort Data using ORDER BY

## Technologies Used
- SQL
- MySQL

## Database Structure

Table: Students

| Column | Data Type |
|----------|----------|
| id | INT |
| name | VARCHAR(50) |
| age | INT |
| city | VARCHAR(50) |
